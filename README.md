# Virtual Cryptography Lab

A collection of interactive web-based cryptography experiments.

## Current Experiments

- **[RC4 Key Scheduling Algorithm (KSA)](./experiments/rc4/README.md)**: Explore the theory, procedure, and a step-by-step interactive simulation of the RC4 stream cipher.

## How to use

Simply open the respective index.html file of the experiment you want to use, or host the repository using a standard web server (like Live Server or GitHub Pages).

## Technologies Used

- Vanilla HTML, CSS, JavaScript
- Font Awesome (Icons)
- Google Fonts
