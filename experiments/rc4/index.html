RC4 Key Scheduling Algorithm

Aim and Objectives

Aim:

To understand, visualize, and implement the RC4 Key Scheduling Algorithm (KSA) and understand how it initializes the state array, followed by the generation of the keystream using the Pseudo-Random Generation Algorithm (PRGA) for encryption and decryption.

Objectives:

  • To visualize the initialization of the 256-byte state array `S`.
  • To understand the swapping mechanism involved during the KSA.
  • To visualize how the PRGA generates the keystream byte by byte.
  • To perform RC4 encryption and decryption on given strings.

Relevant Theoretical Concepts

What is RC4?

RC4 (Rivest Cipher 4) is a stream cipher, designed by Ron Rivest in 1987. It is known for its simplicity and speed in software applications. Rather than processing data in fixed blocks, a stream cipher encrypts data one byte at a time.

The Two Phases of RC4:

1. Key-Scheduling Algorithm (KSA)

The KSA is used to initialize the permutation in the array S. "Keylength" is defined as the number of bytes in the key and can be in the range 1 ≤ keylength ≤ 256, typically between 5 and 16, corresponding to a key length of 40-128 bits. First, the array S is initialized to the identity permutation. S[i] = i for all i from 0 to 255. A secondary array T is also initialized using the provided key.

Then, the array S is processed for 256 iterations in a way that is determined by the key.

2. Pseudo-Random Generation Algorithm (PRGA)

Once the array S has been initialized from the key, the KSA is completed. The PRGA starts taking over and generates sequence of random bits, extracting pseudo-random keystream bytes until the full length of the plaintext has been reached.

For operations, RC4 uses an XOR operation between the keystream bytes generated and the plaintext to produce ciphertext. Since XOR is its own inverse, exactly the same operation is applied for decryption.

Step-by-Step Procedure

1. Key Scheduling Algorithm (KSA)

  1. Initialize an array `S` of size 256, where S[i] = i for i = 0 to 255.
  2. Initialize an array `T` of size 256. If the key length is 256 bytes, copy the key completely into T. If the key is shorter, copy the key repeatedly into T until T is filled.
  3. Set index j = 0.
  4. For i = 0 to 255 do:
    • j = (j + S[i] + T[i]) mod 256
    • Swap the values of S[i] and S[j].

2. Pseudo-Random Generation Algorithm (PRGA)

  1. Initialize indices i = 0 and j = 0.
  2. For each byte of plaintext, do:
    • i = (i + 1) mod 256
    • j = (j + S[i]) mod 256
    • Swap the values of S[i] and S[j].
    • Calculate index t = (S[i] + S[j]) mod 256.
    • The keystream byte is K = S[t].
  3. Ciphertext byte = Plaintext byte XOR Keystream byte (C = P ⊕ K).
